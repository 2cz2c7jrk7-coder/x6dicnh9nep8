# 地图上的人 · 李旭旦互动数字展

[打开作品](https://2cz2c7jrk7-coder.github.io/x6dicnh9nep8/)

一卷关于求知、求实与育人的水墨互动数字展。2026年9月扩展版将观看、观察、思考和保存串成完整体验。

## 内容

- 三条人物叙事：求知、求实、育人。
- 七个人生时间切片，配江阴、南京、剑桥与重庆的行迹关系示意。
- 三层人地关系概念地图，包含五个可探索节点。
- “如果建一座学堂”情境：三个候选地点、平日/雨季、三种调查视角。
- 四本著作与译著的书目卡片、背景和延伸问题。
- 三道史实/创作表达/概念示意辨读互动。
- 四枚探索印记、三种观展笺主题、自定义一句发现、1080×1440 PNG导出。
- 九项集中呈现的机构、文献和书目资料。

## 本地使用

直接打开 `index.html`；无需构建、安装、账号或网络运行依赖。也可在此目录启动任意静态服务器。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

之后浏览 `http://127.0.0.1:4173/`。外部资料链接需要网络。

## 文件

- `index.html`：语义结构、静态正文、地图与对话框。
- `styles.css`：水墨视觉、动画、响应式及键盘焦点样式。
- `data.js`：核对过的生平、书目、来源和明确标注的教学情境。
- `app.js`：图层、年表、情境、辨读和Canvas图片生成。
- `assets/`：三幅本地水墨意象。
- `creation-notes.md`：面向观众的作品说明。
- `docs/`：作品简介、创作及AI使用说明、史料记录。

## 数据与表达边界

史实据公开资料整理；现代解释、标题与寄语不冒充人物原话。生成山水、书案和概念书封不作为历史图像。学堂选址是虚构教学情境，不能代替现场调查或专业评估。

本项目使用Codex辅助策划、撰写、开发与校验，使用内置image_gen生成三幅艺术意象，具体范围见 `docs/` 内的说明。第三方文献仍属于其权利人；引用链接不表示取得重发全文的许可。

## 隐私与可访问性

没有表单提交、后台服务、统计追踪、第三方脚本或外部字体。观展笺输入不会上传；localStorage仅尝试保存四项探索印记，失败不影响使用。默认开启动画，支持手动暂停；支持键盘按钮、明确焦点和图像说明。
