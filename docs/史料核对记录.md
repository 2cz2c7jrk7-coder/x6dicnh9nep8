# 《地图上的人——李旭旦互动数字展》史料与展签文案

本稿供展览内容扩展使用。以下展签均为现代转述；“今天怎样理解”属于策展解释，不是李旭旦原话。只采用高校、研究机构、学术期刊及出版社资料；不使用百科或二手商品页作为最终证据。

## 四本书：署名与约70字卡片

### 《人地学原理》

- 责任者：白吕纳著；任美锷、李旭旦合译。
- 可用书目信息：南京，钟山书局，1935年。南大资料记载二人在大学就读期间合作，不能将翻译开始时间与出版年混为一谈。
- **卡片文案：**求学期间，李旭旦与同窗任美锷合作翻译白吕纳的著作。这是两位青年学者把国外地理思想带入中文阅读的早期实践，也为观察李旭旦此后持续的学术译介提供了一条线索。
- 来源：[南京大学：任美锷学术目录（条目17）](https://www.nju.edu.cn/info/3891/408431.htm)；[南京大学地理学科百年史（任美锷条）](https://sgos.nju.edu.cn/bnyq/af/ff/c47087a569343/page.htm)。书名、合译关系、出版年可信度高。

### 《地理学思想史》

- 责任者：普雷斯顿·詹姆斯著；李旭旦译。此处指1982年中文版。
- 可用书目信息：北京，商务印书馆，1982年。
- **卡片文案：**李旭旦将普雷斯顿·詹姆斯的地理学思想史著作译成中文。沿着学科观念的历史变化阅读世界，构成他晚年译介工作的一部分，也体现了他对学术交流和不同观点之间讨论的重视。
- 来源：[陕西省委党校图书馆书目](https://pear.ilovelibrary.cn/sxswdx/book.aspx?BiblioRecPath=%E5%9B%BE%E4%B9%A6%E6%80%BB%E5%BA%93/222464)；[汤茂林：《李旭旦先生的学术翻译及其反映的学术理念》，《地理研究》2013年第7期](https://www.dlyj.ac.cn/CN/Y2013/V32/I7/1364)。作者、译者、年份可信度高；关于翻译作用的叙述为依据学术研究所作的现代概括。

### 《人文地理学论丛》

- 责任者：李旭旦主编。
- 可用书目信息：北京，人民教育出版社，1985年。学术文献明确列有李旭旦的《人文地理学引论》，页码1—14。
- **卡片文案：**由李旭旦主编的这部论文集，收录了他撰写的《人文地理学引论》。它把学科讨论汇集为书，也留下他晚年推动人文地理学发展的工作线索，展现了编书与研究相互支持的一面。
- 来源：[同济大学图书馆书目](https://webpac.tongji.edu.cn/opac/openlink.php?count=25&displaypg=20&doctype=ALL&lang_code=ALL&location=ALL&match_flag=forward&onlylendable=yes&orderby=DESC&page=2&showmode=list&sort=CATA_DATE&title=%E4%BA%BA%E6%96%87%E5%9C%B0%E7%90%86%E5%AD%A6&with_ebook=off)；[《地理研究》2013年论文及参考文献第13条](https://www.dlyj.ac.cn/CN/article/downloadArticleFile.do?attachType=PDF&id=11577)。主编、年份和篇目可信度高；不要将整书署为“李旭旦著”。

### 《人文地理学概说》

- 责任者：李旭旦主编；各分支章节由相应学者撰写。
- 可用书目信息：北京，科学出版社，1985年。
- **卡片文案：**从人口、城市到文化与旅游，这本书邀请多位学者介绍人文地理的不同方向。李旭旦撰写前言、导言和流派简介，让读者在同一本书中看到学科的共同问题与多样研究路径。
- 来源：[科学出版社：《人文地理学概说》内容简介与目录](https://www.ecsponline.com/goods.php?id=18445)；[同济大学图书馆书目](https://webpac.tongji.edu.cn/opac/openlink.php?count=25&displaypg=20&doctype=ALL&lang_code=ALL&location=ALL&match_flag=forward&onlylendable=yes&orderby=DESC&page=2&showmode=list&sort=CATA_DATE&title=%E4%BA%BA%E6%96%87%E5%9C%B0%E7%90%86%E5%AD%A6&with_ebook=off)。书名、主编、年份可信度高。出版社页面的作者和出版时间栏目前为空，不能只凭该页证明署名与年份，须与馆藏书目联合使用。

## 三条思想：用今天的话解释

### 1. 一个地方，要把人和自然放在一起看

**策展转述：**认识一个地区，既要看山川与气候，也要看人怎样居住、生产和生活。自然与人文相互关联，合在一起才更接近地方的全貌。

**史料依据：**李旭旦主张区域地理兼顾自然与人文，强调地理学的统一性。[东南大学校友总会：李旭旦](https://seuaa.seu.edu.cn/2008/0116/c1672a25963/page.htm)

**互动启发（策展设计，不是历史事实）：**同一幅示意区域，叠加河流、聚落与交通三种信息，邀请观众观察其空间联系。

### 2. 地理不止回答“有什么”，还要追问“为什么”

**策展转述：**地方知识不能停在地名与物产清单上。围绕具体问题，解释各种现象怎样联系，区域研究才更能帮助我们理解变化。

**史料依据：**中科院人物介绍记载，李旭旦倡导以专题性的解释分析推进区域地理研究。[中国科学院地理资源所：地理教育家——李旭旦](https://igsnrr.cas.cn/cbkx/kpyd/dlxj/202009/t20200910_5692705.html)

**互动启发（策展设计，不是历史事实）：**给同一处聚落设置“看到的现象”与“可能的联系”，让观众从观察继续追问。

### 3. 学习世界的理论，也要回答中国的问题

**策展转述：**阅读国外研究，是扩展眼界的起点。理解不同方法之后，还要形成自己的判断，寻找适合实际问题的研究路径。

**史料依据：**有关李旭旦译介工作的学术研究将翻译、国际学术交流和中国人文地理学的复兴联系起来；其倡导分析解决中国实际问题的方向亦见中科院人物介绍。[汤茂林：《李旭旦先生的学术翻译及其反映的学术理念》](https://www.dlyj.ac.cn/CN/Y2013/V32/I7/1364)；[中国科学院地理资源所：地理教育家——李旭旦](https://igsnrr.cas.cn/cbkx/kpyd/dlxj/202009/t20200910_5692705.html)

**互动启发（策展设计，不是历史事实）：**将“读一部译著—比较几种解释—提出本地问题”设置为思考步骤。

## 应保留的史实边界

- **硕士学位年份存在异文。**中科院页面写1936年赴英、两年后获硕士；东南大学页面将获硕士与1939年返国相连。用“在剑桥获硕士学位，1939年回国”，不在展览中指定获学位年。
- **接任地理系主任的具体年份不采用。**南京大学百年史同页分别出现1941年和1942年；展览只写长期从事地理教学、曾任系主任。
- **1952年后的校名使用“南京师范学院”。**南京大学百年史有以现名“南京师范大学”回指历史的写法；展签保留当时校名。
- **《人文地理学概说》保留“概说”。**部分论文、回顾材料出现“概论”的写法；科学出版社实书页面与同济馆藏一致支持“概说”。
- **《地理学思想史》注明具体版本时再写作者。**1982年版书目署普雷斯顿·詹姆斯著、李旭旦译；不要将后续增订本的杰弗雷·马丁、其他新版译者与该版混用。一般书架可只写“李旭旦译”。
- **不写未经核对的精确路线、旅程日期或分区地图。**1947年方案可用来说明自然与人文综合的思想；如果制作地图，应明确“策展示意”，不能将当代行政图标作其原始区划。
- **不将转述排成名人引语。**本稿三条思想和四张卡片均未冒充人物原话，不能加引号后署“李旭旦”。
- **书封采用设计示意时明确标识。**本稿核实的是书目信息，未取得可授权复刻的原版封面，不能把原创概念封面标为史料扫描。
