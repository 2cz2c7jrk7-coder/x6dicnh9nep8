# 地图上的人史料与参考文献

本记录汇总《地图上的人》采用的人物生平、著作书目与学术思想资料，并说明其在作品中的呈现方式。生平和书目信息依据高校、研究机构、学术期刊、出版社及图书馆资料整理；导读、提问和互动设计属于创作阐释。

## 四本书的书目信息

### 《人地学原理》

- 责任者：白吕纳著；任美锷、李旭旦合译。
- 出版信息：南京，钟山书局，1935年。二人的翻译合作始于大学求学期间，1935年为该译本出版年。
- **书目导读：**求学期间，李旭旦与同窗任美锷合作翻译白吕纳的著作。这是两位青年学者把国外地理思想带入中文阅读的早期实践，也为观察李旭旦此后持续的学术译介提供了一条线索。
- 来源：[南京大学：任美锷学术目录（条目17）](https://www.nju.edu.cn/info/3891/408431.htm)；[南京大学地理学科百年史（任美锷条）](https://sgos.nju.edu.cn/bnyq/af/ff/c47087a569343/page.htm)。

### 《地理学思想史》

- 责任者：普雷斯顿·詹姆斯著；李旭旦译。此处指1982年中文版。
- 出版信息：北京，商务印书馆，1982年。
- **书目导读：**李旭旦将普雷斯顿·詹姆斯的地理学思想史著作译成中文。沿着学科观念的历史变化阅读世界，构成他晚年译介工作的一部分，也体现了他对学术交流和不同观点之间讨论的重视。
- 来源：[陕西省委党校图书馆书目](https://pear.ilovelibrary.cn/sxswdx/book.aspx?BiblioRecPath=%E5%9B%BE%E4%B9%A6%E6%80%BB%E5%BA%93/222464)；[汤茂林：《李旭旦先生的学术翻译及其反映的学术理念》，《地理研究》2013年第7期](https://www.dlyj.ac.cn/CN/Y2013/V32/I7/1364)。关于翻译作用的叙述为依据学术研究所作的现代概括。

### 《人文地理学论丛》

- 责任者：李旭旦主编。
- 出版信息：北京，人民教育出版社，1985年。学术文献明确列有李旭旦的《人文地理学引论》，页码1—14。
- **书目导读：**由李旭旦主编的这部论文集，收录了他撰写的《人文地理学引论》。它把学科讨论汇集为书，也留下他晚年推动人文地理学发展的工作线索，展现了编书与研究相互支持的一面。
- 来源：[同济大学图书馆书目](https://webpac.tongji.edu.cn/opac/openlink.php?count=25&displaypg=20&doctype=ALL&lang_code=ALL&location=ALL&match_flag=forward&onlylendable=yes&orderby=DESC&page=2&showmode=list&sort=CATA_DATE&title=%E4%BA%BA%E6%96%87%E5%9C%B0%E7%90%86%E5%AD%A6&with_ebook=off)；[《地理研究》2013年论文及参考文献第13条](https://www.dlyj.ac.cn/CN/article/downloadArticleFile.do?attachType=PDF&id=11577)。该书署名为李旭旦主编。

### 《人文地理学概说》

- 责任者：李旭旦主编；各分支章节由相应学者撰写。
- 出版信息：北京，科学出版社，1985年。
- **书目导读：**从人口、城市到文化与旅游，这本书邀请多位学者介绍人文地理的不同方向。李旭旦撰写前言、导言和流派简介，让读者在同一本书中看到学科的共同问题与多样研究路径。
- 来源：[科学出版社：《人文地理学概说》内容简介与目录](https://www.ecsponline.com/goods.php?id=18445)；[同济大学图书馆书目](https://webpac.tongji.edu.cn/opac/openlink.php?count=25&displaypg=20&doctype=ALL&lang_code=ALL&location=ALL&match_flag=forward&onlylendable=yes&orderby=DESC&page=2&showmode=list&sort=CATA_DATE&title=%E4%BA%BA%E6%96%87%E5%9C%B0%E7%90%86%E5%AD%A6&with_ebook=off)。书名与内容依据出版社目录，主编身份及出版年份依据馆藏书目。

## 学术思想与互动呈现

### 1. 一个地方，要把人和自然放在一起看

**策展转述：**认识一个地区，既要看山川与气候，也要看人怎样居住、生产和生活。自然与人文相互关联，合在一起才更接近地方的全貌。

**史料依据：**李旭旦主张区域地理兼顾自然与人文，强调地理学的统一性。[东南大学校友总会：李旭旦](https://seuaa.seu.edu.cn/2008/0116/c1672a25963/page.htm)

**作品中的呈现：**概念地图设置自然环境、聚落分布与人的活动三个图层，邀请观众观察其空间联系。

### 2. 地理不止回答“有什么”，还要追问“为什么”

**策展转述：**地方知识不能停在地名与物产清单上。围绕具体问题，解释各种现象怎样联系，区域研究才更能帮助我们理解变化。

**史料依据：**中科院人物介绍记载，李旭旦倡导以专题性的解释分析推进区域地理研究。[中国科学院地理资源所：地理教育家——李旭旦](https://igsnrr.cas.cn/cbkx/kpyd/dlxj/202009/t20200910_5692705.html)

**作品中的呈现：**观众点选山地、河流、聚落、田地与往来标记，从空间位置继续提出问题。

### 3. 学习世界的理论，也要回答中国的问题

**策展转述：**阅读国外研究，是扩展眼界的起点。理解不同方法之后，还要形成自己的判断，寻找适合实际问题的研究路径。

**史料依据：**有关李旭旦译介工作的学术研究将翻译、国际学术交流和中国人文地理学的复兴联系起来；其倡导分析解决中国实际问题的方向亦见中科院人物介绍。[汤茂林：《李旭旦先生的学术翻译及其反映的学术理念》](https://www.dlyj.ac.cn/CN/Y2013/V32/I7/1364)；[中国科学院地理资源所：地理教育家——李旭旦](https://igsnrr.cas.cn/cbkx/kpyd/dlxj/202009/t20200910_5692705.html)

**作品中的呈现：**译著导读连接学术交流与地理思考，学堂选址情境引导观众结合具体条件提出调查问题。

## 资料采用与表达说明

- 留学经历采用1936年赴英、1939年归国两个节点。授位年份和接任系主任年份在部分来源中存在异文，展览没有指定这两个年份。
- 1952年后的创系经历使用当时校名“南京师范学院”。《人文地理学概说》的书名依据科学出版社目录与同济大学馆藏书目。
- 《地理学思想史》的书目介绍对应普雷斯顿·詹姆斯著、李旭旦译的1982年中文版。
- 1947年地理分区研究用于介绍综合自然与人文因素的学术视角；网页中的行迹图、概念地图与学堂情境均为教学设计，不是原始区划图或历史研究场景复原。
- 导读、标题、提问和寄语属于现代创作表达。书封为概念设计，不是原书封面扫描。
