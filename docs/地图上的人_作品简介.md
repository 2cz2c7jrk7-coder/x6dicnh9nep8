# 地图上的人 作品简介

《地图上的人》是一件以江苏江阴籍地理学家、地理教育家李旭旦为主题的互动数字展。作品以求知、求实与育人为线索，结合水墨长卷、人物年表、著作书架和概念地图，引导观众从具体经历与主动探索中理解科学家精神。

展览以连续卷轴组织内容。观众可点选年表节点，了解李旭旦留学归国、开展地理研究及投身教育的经历；也可翻阅四本相关著作的介绍，辨认他作为译者或主编参与知识传播的不同方式。人物叙述附有公开资料出处，便于继续阅读和核验。

地图互动将自然环境、聚落分布和人的活动分为三个可切换图层，使抽象的人地关系变得可观察。假设教学情境“为村落选择学堂位置”提供三处候选地点，可切换平日与雨季、调整调查重点，比较条件变化下的权衡。三道辨识题帮助观众区分史实、艺术表达和概念示意，四枚探索印记记录本地观展进度。

观展结束后，观众可选择主题、写下36字以内的感想，在浏览器中生成并下载PNG观展笺。网站适配手机和电脑，提供可暂停的动态效果，也可使用键盘操作主要交互。作品以静态网页及本地素材交付，联网可访问公开网址，下载完整文件后可离线打开，外部参考资料仍需联网。
