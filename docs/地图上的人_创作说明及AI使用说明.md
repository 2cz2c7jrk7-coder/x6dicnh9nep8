# 地图上的人 创作说明及AI使用说明

## 创作背景与主题

《地图上的人》以李旭旦的地理研究与教育经历为内容基础，采用互动数字展的形式呈现科学家精神。李旭旦来自江苏江阴，其求学、翻译、研究与育人经历，与江苏高校的学科发展相联系。作品选择可核验的生平节点和著作线索，将对人物的认识落实到具体经历和工作之中。[1][2]

创作关注两件事：观众如何认识一位地理学家，以及如何体验地理学观察人与环境的方式。人物部分呈现李旭旦的求知与育人经历；互动部分让观众主动比较条件、说明理由，并辨识不同类型的信息。这里的教育目标是培养追问和核验的习惯，互动结论不等同于李旭旦本人的观点或研究结论。

## 具体内容与交互设计

水墨长卷与人物叙事共同构成展览入口。山水、纸张和书案意象提供阅读氛围，章节围绕求知、求实与育人展开。页面标题、章节叙述及结语为创作者组织表达，引用的人物事实可通过页面资料入口继续查阅。

年表以七个可点选年份节点串联生平，呈现经历说明与资料依据。著作书架介绍《人地学原理》《地理学思想史》《人文地理学论丛》《人文地理学概说》，明确李旭旦的合译、翻译或主编身份。书架用于导读，不提供整本图书文本。[3][6][7][8]

概念地图设置自然环境、聚落分布和人的活动三个图层，以及五个可点选标记。切换图层可观察不同要素的联系；背景山水始终作为绘画保留，开关控制概念标记与连线，帮助观众区分画面氛围和教学信息。

“为村落选择学堂位置”是假设教学情境，设置三处候选地点、平日与雨季两种条件，以及三种调查重点。观众改变条件后阅读相应反馈，比较地形、通行及服务需求的权衡。情境不对应真实村落，不提供实际建设建议，也不作为李旭旦具体研究成果的复原。

三道辨识题区分史实、艺术表达和概念示意，回答后提供解释。四枚本地探索印记记录观展进度。观展笺提供求知、求实、育人三个主题，可填写36字以内的感想，并由浏览器生成1080×1440像素PNG图片下载留存。自写感想不上传，也不持久保存。

## 技术实现与AI工具使用

作品采用HTML、CSS和JavaScript构建纯静态网站，使用浏览器原生能力完成年表切换、图层控制、书架点选、情境选择、答题反馈和观展笺生成。图片随网站文件提供，字体优先调用设备系统字体，不分发商业字体文件。动态效果默认开启，提供暂停与恢复入口，页面采用响应式布局。localStorage仅保存四枚探索印记的完成旗标，浏览器限制本地存储时仍可继续互动。

### Codex

Codex用于辅助整理公开史料与书目信息、拟定和修改页面文案、设计交互结构、生成HTML、CSS及JavaScript代码，并协助检查页面表现、修复问题和优化使用体验。资料整理和文字生成均以来源核对为前提，AI输出本身不作为人物史实的证据。

### OpenAI内置图像生成工具

image_gen用于生成展览中的两幅水墨山水意象及新增的书案静物。图像服务于章节氛围、阅读节奏和视觉统一，不表现可据以考证的李旭旦肖像、手稿或历史现场，也不使用虚构文字冒充图书原页。图像在网页中作为艺术素材使用。使用界面未显示底层图像模型版本，本说明不对版本号作推定。

参赛者负责选题取舍、提出修改意见和最终审核，对作品的人物叙述、互动设置与对外呈现作出最终判断。AI参与范围以本说明记录的工具及用途为准，史料来源、生成图像和程序交互均纳入最终审核。

## 史实与图像边界

人物经历以中科院地理所、学术期刊、大学和出版社公开资料为依据。出生信息仅注明1911年；留学经历表述为1936年赴英、1939年归国，授位年份因来源异文未采用。关于1952年后创系的叙述使用当时校名“南京师范学院”，避免以现名替代历史名称。[1][2]

书名、年份与署名分别核对。采用《人文地理学概说》，明确李旭旦为主编；《人地学原理》注明任美锷、李旭旦合译；《地理学思想史》对应普雷斯顿·詹姆斯所著、李旭旦所译的1982年中文版，不混入后续增订版的作者或译者信息。[3][6][7][8]

水墨山水、书案静物和书架中的视觉处理均属艺术表达，不是历史照片、文物影像或原书封面复刻。地图没有地理坐标、测绘精度或实测数据；选址情境与辨识题由创作者为教学目的编排。人物事实、创作者叙述和交互示意在页面中分别说明。
